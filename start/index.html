Κώδικας

Από πού να ξεκινήσω από το μηδέν;#

Εγώ ξεκίνησα με ένα Udemy course, από το Zero to Mastery για web development, κ μετά έκανα πάρα πολλά personal projects μόνη μου. Τα hackathons έδιναν έναν έξτρα λόγο να φτιάξω κάτι.

Αν θες κάτι πιο οργανωμένο, δες το DevReady (affiliate link).

Βλέπω tutorials κ δεν μου μένει τίποτα#

Καταλαβαίνω το struggle, είναι δύσκολο με τα tutorials ειδικά τώρα που ξέρεις ότι το AI μπορεί να σου κάνει όλη τη δουλειά. Ο καλύτερος τρόπος να μάθεις μια γλώσσα σε βάθος είναι να φτιάξεις ένα δικό σου project από την αρχή, πχ ένα μικρό CRUD app με βάση δεδομένων. Απλά όσο γίνεται χωρίς AI :)

Αλλάζω καριέρα κ ξέρω τα βασικά. Τι κάνω;#

Θα πρότεινα να διαλέξεις ένα stack κ να μείνεις σε αυτό, πχ Python με FastAPI κ PostgreSQL. Μετά φτιάξε ένα δικό σου project από την αρχή: ένα API με login, βάση δεδομένων κ deploy κάπου που να το ανοίγει όποιος θέλει. Όσο γίνεται χωρίς AI στην αρχή.

Το παιδί μου είναι 12. Πού να μάθει να χρησιμοποιεί AI;#

Δεν έχω κάποιο συγκεκριμένο μάθημα να προτείνω με σιγουριά. Στα 12 το καλύτερο ξεκίνημα είναι να παίξει το ίδιο με απλά AI εργαλεία υπό επίβλεψη, πχ να φτιάξει κάποιο παιχνίδι ή εφαρμογή με έναν AI builder όπως το Lovable ή το Replit.

Ποιο laptop να πάρω για προγραμματισμό;#

Κοίτα κυρίως 16GB RAM κ SSD τουλάχιστον 512GB. Αν χωράει στο budget, ένα MacBook Pro με M chip είναι πολύ καλή επιλογή, αλλιώς οποιοδήποτε laptop με αυτά τα specs κάνει τη δουλειά (κ φρόντισε να βάλεις Linux). Με 24 ή 32GB even better ;)

Με τι κάνεις το αυτόματο μοντάζ στα reels;#

Με Claude Code κ ένα skill που έφτιαξα, για ελληνικούς υπότιτλους, κόψιμο κενών, zoom κ SFX. Είναι ανοιχτό: github.com/artemisln/edit-reel

Πανελλήνιες κ διάβασμα

Αξίζει να ξαναδώσω Πανελλήνιες;#

Εξαρτάται από το τι θέλεις να κάνεις μετά. Αν το επάγγελμα που σε ενδιαφέρει απαιτεί συγκεκριμένο πτυχίο, αξίζει να ξαναδώσεις. Αν όχι, υπάρχουν κ άλλοι δρόμοι, όπως τα ΣΑΕΚ ή το Ανοικτό Πανεπιστήμιο αργότερα.

Για πληροφορική θα πρότεινα να μην χάσεις άλλη μια χρονιά για όνομα σχολής. Μπες σε όποια μπορείς τώρα κ ξεκίνα να χτίζεις πράγματα από την αρχή, αυτό μετράει πολύ περισσότερο από ΑΠΘ/ΕΚΠΑ στο cv σου. Πολλοί είναι κ senior developers χωρίς πτυχίο.

Ό,τι κ να αποφασίσεις, καλή τύχη κ καλή αρχή :)

Πώς διαβάζω χωρίς φροντιστήριο;#

Μην αφήσεις κενά στην ύλη, ειδικά στα μαθήματα που δυσκολεύεσαι πιο πολύ. Προχώρα συστηματικά κ κάνε πολλές επαναλήψεις ασκήσεων, όχι μόνο θεωρία.

Τα flashcards μου για οικονομικά, πληροφορική κ μαθηματικά είναι εδώ.

Να κοιμάμαι 5 ώρες για να προλάβω;#

Θα πρότεινα να μη θυσιάσεις τον ύπνο. Κοιμήσου 7 με 8 ώρες κ κόψε από αλλού, πχ μην χρησιμοποιείς κινητό όσο διαβάζεις. Στα διαγωνίσματα δούλεψε πρώτα τα κεφάλαια που πέφτουν πιο συχνά. Το «είμαι πίσω» το νιώθουν σχεδόν όλοι αυτή την εποχή.

Πώς μαθαίνω Αγγλικά χωρίς φροντιστήριο;#

Το πιο πρακτικό είναι να βλέπεις καθημερινά περιεχόμενο στα αγγλικά που σε ενδιαφέρει, πχ σειρές ή YouTube με αγγλικούς υπότιτλους αντί για ελληνικούς. Για λεξιλόγιο δοκίμασε Duolingo ή Anki, κ για προφορική εξάσκηση δωρεάν apps όπως Tandem ή HelloTalk, όπου μιλάς με native speakers. Το'χεις κ καλή αρχή!

Καίω τη μέρα μου σε reels. Πώς το κόβω;#

Κλασικό. Βάλε time limit στην εφαρμογή κ κάνε το κινητό σου full βαρετό (υπάρχουν YouTube tutorials που το κάνουν σαν dumb phone). Το Instagram μπορείς να το σβήσεις από τις εφαρμογές κ να μπαίνεις από το browser που είναι λίγο χάλια, ή να πεις στους φίλους σου να μιλάτε σε Viber/WhatsApp.

Έχε πάντα ένα μικρό coding project έτοιμο κ ανοιχτό για τη στιγμή που θες να σκρολάρεις. Δοκίμασε τις πρώτες 1-2 ώρες που ξυπνάς να μην ανοίγεις καθόλου social media.

Πληροφορική κ δουλειά

Αξίζει ακόμα η πληροφορική με το AI;#

Θεωρώ ότι αξίζει, το AI αλλάζει το πώς γράφουμε κώδικα αλλά χρειάζονται ακόμα άτομα που καταλαβαίνουν τι φτιάχνουν. Απλά το πτυχίο μόνο του δεν αρκεί πια, θέλει projects κ πρακτική από νωρίς. Θα έκανα 10% μόνο αν με τραβούσε πραγματικά κάτι άλλο, όχι από φόβο για το AI.

Πού ψάχνω remote δουλειά;#

Στο LinkedIn Jobs με φίλτρο Remote, κ σε boards όπως We Work Remotely κ Remote OK. Πολλές ξένες εταιρείες με γραφείο στην Αθήνα δουλεύουν μόνο στα αγγλικά, οπότε ψάξε κ «Athens» στο LinkedIn.

Τι θέμα να διαλέξω για πτυχιακή;#

Εξαρτάται τι θες μετά. Αν σκέφτεσαι μεταπτυχιακό ή έρευνα, η δημοσίευση μετράει πολύ. Αν θες να δουλέψεις σε εταιρεία, κάτι που μπορείς να δείξεις είναι πιο χρήσιμο στο πορτφόλιο.

Για πτυχιακή με AI agent, ένα καλό τεστ είναι αν τα βήματα δεν είναι γνωστά από πριν. Πχ ένας agent που παίρνει ένα GitHub issue, διαβάζει το repo, προσπαθεί να αναπαράγει το bug τρέχοντας τα tests κ προτείνει fix. Μπορείς να το αξιολογήσεις με νούμερα (πόσα issues έλυσε σωστά).

Hackathons

Χρειάζομαι εμπειρία για να πάω σε hackathon;#

Όχι, τα περισσότερα είναι ανοιχτά κ σε άτομα από business, κ ομάδα φτιάχνεις κ εκεί αν δεν έχεις. Φέρε μόνο το λάπτοπ σου. Για γλώσσα κ προϋποθέσεις τσέκαρε το σάιτ του κάθε διαγωνισμού.

Πώς φτιάχνω κάτι που ξεχωρίζει;#

Το πιο σημαντικό tip θεωρώ για διαγωνισμό: διάλεξε ένα πρόβλημα που μπορείς να δείξεις να δουλεύει live σε 2 λεπτά, κ χτίσε μόνο αυτό. Κράτα 3 με 4 ώρες στο τέλος για το demo κ το pitch.

Ευκαιρίες

Ποιο είναι αυτό με την Αμερική από το βίντεο;#

Είναι το Jon Vlachogiannis Fund. Αν σπουδάζεις ή κάνεις έρευνα στην Ελλάδα κ σου έχει γίνει δεκτό paper, poster ή workshop σε συνέδριο για AI, όπως το NeurIPS ή το ICML, σου πληρώνει το ταξίδι στην Αμερική για να το παρουσιάσεις (αεροπορικά, διαμονή κ 500$ τη μέρα). Προς το παρόν μόνο για συνέδρια στις ΗΠΑ.

Η σελίδα του CERN λέει ότι δεν υπάρχει κάτι ανοιχτό#

Απλά δεν έχει βγει ακόμα η πρόσκληση. Συνήθως ανοίγει τον χειμώνα κ κλείνει τέλος Ιανουαρίου. Τσέκαρε το Summer Student Programme μέσα στον Δεκέμβρη. Θέλει να έχεις τελειώσει 6 εξάμηνα μέχρι το καλοκαίρι.

Πώς πήγες στο event του YC στο Σαν Φρανσίσκο;#

Ήταν το AI Startup School του Y Combinator, δωρεάν event για φοιτητές κ νέους builders. Μπήκα στα 18 χωρίς δική μου startup. Κάνεις αίτηση με μια σύντομη φόρμα για το τι έχεις φτιάξει κ καλύπτουν 500$ για το ταξίδι. Τσέκαρε τη σελίδα events του YC κ φτιάξε πράγματα που μπορείς να δείξεις.

Πάω Σαν Φρανσίσκο. Τι να κάνω εκεί;#

Θεωρώ το πιο σημαντικό είναι να πας σε όσο περισσότερα events μπορείς (πχ στο Luma ή στο Cerebral Valley για AI) κ να μιλάς κατευθείαν με founders, όχι μόνο με recruiters. Έχε κ ένα project live που να ανοίγει από το κινητό για να το δείχνεις.

Δεν το βρήκες εδώ; Στείλε μου στο Instagram.
